# Decision Tree Classifier with Banknote Authentication Dataset
This project is made for Homework of ELE489: Fundamentals of Machine Learning course. In this project, machine learning techniques is applied to classify banknotes as fake or authentic using a Decision Tree Classifier.  

## Project Structure
- `HW2_2200357047_GayeAksu.pdf`: Report of project.
- `banknote_decision_tree.ipynb`: Main notebook with data loading, visualization, model training, evaluation, and conclusions.
- `data_banknote_authentication.txt`: Dataset used for training and testing.

## Dataset
The dataset is downloaded form [this site](https://archive.ics.uci.edu/dataset/267/banknote+authentication)

## Models
We trained and compared different Decision Tree models using Gini and Entropy criteria.

## Visualizing
We evaluated each model using:
- Confusion Matrix
- Classification Report
- Feature Importance Visualizations
- Decision Tree Structure
